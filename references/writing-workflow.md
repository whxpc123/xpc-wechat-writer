# 正文编辑流水线

把正文当作需要多轮编辑的作品，不把初稿直接交给去 AI 味工具。每次写作依次完成写前编辑卡、事实锁定、结构初稿、结构编辑、句子编辑和读者验收。

## 写前编辑卡

创建 `writing-plan.md`，至少包含以下字段。

- `文章原型`，从现象解读、调查实验、方法分享、政策趋势中选择一个
- `核心判断`，只写一句，终稿必须在前 600 字完整出现
- `开头锚点`，一个可核实的事件、人物、物件、截图或数字
- `读者问题`，使用数字列表写恰好三个，按阅读顺序排列
- `情绪曲线`，例如好奇、怀疑、验证、释然，不把每篇都写成焦虑和危机
- `回环对象`，结尾回到开头的物件、数字或问题
- `当天动作`，读者在一天内可以真正完成的一件事

核心判断不是标题复述，也不是正确但空泛的价值观。它需要同时回答发生了什么、普通人为什么在意、作者做出什么判断。

## 选择文章原型

只选一种主原型。其他结构可以局部借用，但不能混成报告目录。

### 现象解读

具体事件 → 常见解释 → 反常之处 → 关键证据 → 作者判断 → 普通人的动作 → 回环。

适合产品变化、社会现象和认知议题。核心判断要在证据全部展开前出现，让读者知道文章为何值得继续读。

### 调查实验

真实问题 → 可复核规则 → 逐项揭晓 → 错误与返工 → 结果分配表 → 使用边界 → 回环。

只有实际执行过测试才写第一人称。公开沙盘要明确标注，不冒充真实顾客、老板或经营结果。多产品展示按信息价值逐次升级，不预设总冠军。

### 方法分享

具体困境 → 常见错误 → 核心方法 → 完整示例 → 失败条件 → 当天清单 → 回环。

每一节都要交付一个动作。不能只提供提示词，还要说明输入条件、检查方法、返工成本和何时停止使用 AI。

### 政策趋势

普通人场景 → 改变了什么 → 没改变什么 → 谁先受影响 → 可做准备 → 不确定性 → 回环。

政策目标不等于落地结果，招聘需求不等于录用，扶持计划不等于人人适合参与。把原文事实和作者推断分开。

## 事实锁定

创建 `fact-lock.md`，使用表格记录以下字段。

| 正文用途 | 不可改写的事实 | 来源 | 统计或适用边界 | 作者判断 |
|---|---|---|---|---|

事实栏保留数字、时间、样本、对象和原始措辞。作者判断栏可以表达观点，但不能扩大事实。另列出三部分。

- `禁止扩大`，记录不能从来源推出的结论
- `第一人称依据`，记录真实完成过的阅读、测试或操作；没有则写无
- `待核实项`，正式写作前必须清零，无法核实的素材从正文移除或明确标注限制

待核实项清零后在标题下单独写 `无`，不要保留空白列表或把未知内容换一个名称继续写进正文。

去 AI 味和标题优化不得修改事实锁。确需修改时，先更新来源与边界，再修改正文。

## 两轮编辑

第一轮只编辑结构。

- 检查开头是否在 200 字内出现具体锚点
- 检查核心判断是否在前 600 字完整出现
- 删除重复解释和不推进主线的背景
- 把过晚的关键判断移到证据之前
- 检查事实、作者判断和读者动作是否自然衔接
- 默认尝试压缩初稿 10% 至 15%，但不为达到比例删除必要证据
- 结尾回到开头，同时给出新的理解，不重复摘要

第二轮只编辑句子。

- 先删除无意义连接词和模板句
- 打破连续对称、等长和过度完整的句子
- 合并机械碎句，拆开负担过重的长句
- 用事实锁中的具体细节替换抽象总结
- 保留不确定性、失败条件和统计边界
- 不为口语化添加粗口、网络口癖或虚构经历

## 小标题和移动阅读

不使用研究报告式标题。现象解读和叙事文章通常使用 0 至 4 个自然转场标题；方法、调查和政策文章可以使用 3 至 7 个帮助定位的标题。标题要推进疑问，不重复大纲名称。

控制段落呼吸，但不要强迫每句话独立成段。连续三个相同长度、相同语法或相同开头的段落需要重新调整。

## 编辑报告

创建 `edit-report.md`，至少记录以下内容。

- 初稿和终稿字符数，以及是否压缩
- 核心判断在终稿中的位置
- 删除、合并或前移的主要内容
- 去掉的模板表达和仍保留的特殊表达
- `事实核对：通过`，确认所有数据、来源和限制与 `fact-lock.md` 一致
- `读者测试：通过`，写明读者读完后对三个问题的答案
- 未消除的风险或限制；没有则写无

读者测试的三个问题是，发生了什么，与我有什么关系，我今天能做什么。任一答案只能用空泛价值观回答时，正文还没有完成。
